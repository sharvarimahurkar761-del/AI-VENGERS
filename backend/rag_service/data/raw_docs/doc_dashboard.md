# Understanding the PulseIQ Dashboard

The PulseIQ Dashboard is your central hub for monitoring system health, user engagement, and key performance indicators (KPIs) in real-time. Designed with a modular architecture, the dashboard can be customized to suit the specific needs of different team members, from marketers to DevOps engineers.

### Core Components

**1. The Overview Ribbon**
Located at the top of the dashboard, the Overview Ribbon displays top-level metrics: Active Users (last 24 hours), System Error Rate, and Average Response Time. These metrics are color-coded (green, yellow, red) based on your custom threshold settings, providing an immediate snapshot of system health.

**2. Engagement Charts**
The main body of the default dashboard features time-series charts visualizing user engagement. You can toggle between line, bar, and area charts. The default view shows "Daily Active Users" vs. "New Signups". Hovering over data points provides exact figures for that specific hour or day.

**3. Real-Time Event Stream**
On the right-hand sidebar, the Real-Time Event Stream provides a live, scrolling feed of significant system events, such as new user registrations, payment failures, or triggered alerts. You can pause this stream or filter it by event severity (Info, Warning, Error, Critical).

### Customizing Your View
Every widget on the dashboard can be resized or moved using a drag-and-drop interface. To add new widgets, click the "+ Add Widget" button in the bottom right corner. You can create multiple dashboard tabs (e.g., "Marketing", "Engineering") and share them with specific roles within your workspace.
